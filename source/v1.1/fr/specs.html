PTC

Protocole et spécifications

Le Protocole de Transparence Canaliste (PTC) est publié sous la forme d’un corpus ouvert de six documents aux fonctions distinctes. Validator.es est une implémentation de référence ; ce n’est pas le protocole.

Carte du corpus

Le noyau commun se combine avec des profils et formats spécialisés. ARCH traverse l’ensemble comme cadre architectural. FRS-01 peut être utilisé directement ou dans Package Format 2.0 ; DCL-03 est une extension optionnelle du parcours « fichier exact ».
