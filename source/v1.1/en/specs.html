PTC

Protocol and specifications

The Canal Transparency Protocol (PTC) is published as an open corpus of six documents with distinct functions. Validator.es is a reference implementation; it is not the protocol.

Corpus map

The shared core combines with specialised profiles and formats. ARCH spans the whole set as the architectural framework. FRS-01 can be used directly or within Package Format 2.0; DCL-03 is an optional extension of the exact-file path.
