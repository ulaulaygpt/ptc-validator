# validator.es

Implementación de referencia del Protocolo de Transparencia Canalista (PTC).

Crea y verifica declaraciones verificables sobre la participación de la IA en documentos
y archivos digitales. Todo el procesamiento es local: ningún archivo sale del navegador.

## Publicación

**DOI:** 10.5281/zenodo.21833853  
**ORCID:** 0009-0000-8891-7021  
**Sitio:** https://validator.es

## Integridad de esta publicación

El SHA-256 de esta publicación se identifica por el nombre del archivo de distribución
publicado en Zenodo junto al registro DOI 10.5281/zenodo.21833853. Para verificar:

1. Calcula el SHA-256 del ZIP que descargaste.
2. Compara con el hash que aparece en el nombre del archivo publicado en Zenodo.
3. Si coinciden, la copia es íntegra e idéntica a la publicación de referencia.

El hash no se incluye dentro del propio artefacto porque hacerlo modificaría los bytes
que pretende identificar.

## Uso

Abre `index.html` en un navegador moderno. No requiere servidor ni instalación.

Para uso en servidor HTTP o desde validator.es, el comportamiento es idéntico.
