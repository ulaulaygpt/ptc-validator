About Validator

Validator.es is the public reference implementation of the Canal Transparency Protocol (PTC): an open tool for creating and verifying transparency declarations about human–AI involvement, cryptographically bound to the protected digital object.

What each part is

PTC

The standard

Defines what is declared, how the declaration is bound to the protected object and how it is verified under the applicable profile.

Validator

The implementation

Applies PTC in the browser to create and verify declarations and, where applicable, source files, packages and public disclosure.

El Canal

The conceptual origin

The broader framework from which PTC emerged. It provides context, but knowing it is not required to use Validator or implement the protocol.

ACS-6

The predecessor

An earlier conceptual stage before the current PTC corpus. It is preserved as a historical record, not as a current technical specification.

Publication, versions and authority

The current specifications published under “Protocol and specifications” are the authoritative source for technical conformance. This page and ACS-6 add no normative requirements.
Protocol

Independent use

PTC is intended to remain independent of El Canal and of any single implementation. Validator can be used, or the protocol implemented, without adopting its original conceptual language.
